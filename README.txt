우리단지 방역관리 체험 v0.2

1. 압축을 풀고 index.html을 컴퓨터 브라우저로 열어 체험하세요.
2. 입주민 탭에서 가상 동·호수로 예약해 보세요.
3. 방역 직원 탭에서 상태를 바꾸면 관리사무소 탭의 통계가 바뀝니다.
4. 동일 브라우저에서 새로고침해도 체험 기록이 남습니다(localStorage).
5. PWA 홈 화면 설치와 오프라인 캐시는 HTTPS 또는 localhost 서버 환경에서만 정상 동작할 수 있습니다.

주의: 서버와 데이터베이스가 없는 프런트엔드 체험 버전입니다. 다른 기기와 실시간 동기화되지 않습니다. 로그인·본인확인·개인정보 보호·문자 발송·실제 방역 예약은 미구현입니다. 실제 주민 개인정보를 입력하지 마세요.

로고 SVG는 앞서 확정한 파랑·초록·주황의 브랜드 방향을 반영한 웹용 단순화 아이콘입니다.
