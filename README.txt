단지온결 v1.6 — 독립 브랜드 최종 정리 및 방역 신청 개선

[브랜드]
홈페이지에 표시되는 서비스 이름: 단지온결
기존 별도 사업 홈페이지는 수정하지 않습니다.
현재 GitHub 저장소/주소는 그대로 사용하며, 주소창의 GitHub 계정명은 변경되지 않습니다.

[주민 방역 신청]
- 아파트 검색 및 동·호수 선택
- 분무 방역 / 겔·트랩 약제 / 분무+겔·트랩 선택
- 직접 방문 / 우편함 겔·트랩 전달 요청 선택
- 분무만 선택한 경우 우편함 전달은 신청 불가
- 신청하기를 누르면 전화 화면으로 이동하지 않고 해당 브라우저에 체험 신청 저장
- 작업 현황 및 CSV에 방역 방법과 전달 요청 표시
- 우편함 전달은 안전·제품 표시사항을 검토한 뒤 가능 여부 결정. 요청만으로 전달 완료가 아님

[기존 기능 유지]
전국 아파트 이름·주소 검색, 현장 아파트 추가, 주민 접수, 관리사무소 현황,
방역 직원 작업표, 전화·문자 문의 버튼, 벌레 상담 캐릭터.
전화·문자 연결번호는 기존 설정을 변경하지 않았습니다.

[중요: 현재 데모 한계]
GitHub Pages 정적 체험판으로 접수는 해당 기기 브라우저에만 저장됩니다.
다른 기기의 관리사무소·방역업체에 자동 전달되지 않으며 실제 운영 접수 시스템이 아닙니다.
실시간 공유, 로그인/권한 관리, 서버 사진 저장, 실제 AI 사진 판별 기능은 별도 구축 필요.
개인정보를 실제로 입력받는 운영에는 사용하지 마세요.

[GitHub 업로드]
ZIP을 압축 해제하고 파일 8개를 GitHub 저장소 루트에 모두 업로드하세요.
ZIP 파일 자체는 업로드하지 마세요. Commit changes를 누른 뒤 배포를 기다립니다.

[v1.7] 벌레 상담 도우미에 진드기(집먼지/참진드기), 바퀴, 빈대, 모기, 초파리, 개미, 쥐의 종류/영향/대처/주의 상세 답변 추가. 사진 자동 판별은 미지원.

[v1.8] 아파트 검색 결과 클릭 시 바로 입주민/관리사무소/방역 직원 화면으로 이동. 전화 접수 대행에 아파트 검색·클릭 선택 추가. 접수는 이 브라우저에만 저장되며 자동 문자 전송은 지원하지 않습니다.
